# Rule order note: every group below lists Disallow before Allow. Modern
# crawlers (RFC 9309) pick the longest matching rule, so order is irrelevant
# to them, but simpler order-based parsers return the first match — and with
# "Allow: /" first those would treat /casestudy/ as crawlable. Disallow-first
# gives the same answer under both interpretations.

# Internal case-study template/demo tool — not a real page, not in the sitemap.

# Both groups below carry an IDENTICAL rule set, and each is written as one
# group with many User-agent lines rather than one block per bot. A named bot

# what let policies drift apart and get flagged as inconsistent. Sharing a
# single rule set makes divergence structurally impossible: to change the AI
# policy, edit one Disallow/Allow pair.
